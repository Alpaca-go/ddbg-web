## 易混淆项（批注前必读）

| 概念 | 说明 |
|------|------|
| **走廊段 catalog** vs **房间战斗几何** | `corridor_tile:p006`–`p014` 是 Phase 1 走廊段数据（Q-45 / R-046）。同一份 raw `dungeon_tile:p006` 等也被 **房间** `room_tile_geometry.json` 引用（例如 `room_tile:p006:front` = Prophet Room，**R-167 已批几何**）。房间 25 面几何「已绿」**不**等于走廊 `segments` 已核实。 |
| **QuestMap 灰点** vs **走廊 tile 灰点** | QuestMap FRONT 上的红点 X（**R-114**）是地图尺度「长走廊须停留」语义，与 R14 规则书一致；**本条工作表**的「灰点」指 **TILES FRONT 板块图面上的走廊节点**（R-046 延后）。二者不能互相替代。 |
| **连接口 label** vs **右上印刷编号** | normalize 将右上象限（`bbox[0]>250` 且 `bbox[1]<20`）的单独数字记为 `sheetNumber`，**不**进 `ports`（见 `corridor-tile.ts`）。 |
| **span 可证** vs **目视几何** | 已入库 `ports` 仅来自 PDF 文字 span 的数字 / `N-M` 标签 + bbox 中心（毫米，TrimBox 270×270）。**区域、共享边、角点通行、段内灰点、容量、走廊端点朝向** 均无批准表 → 一律 **待确认**（R-048）。 |

## 坐标说明

- `ports[].x/y`：TrimBox 毫米，**span bbox 中心**（normalize），不是多边形顶点。
- 下表「span 象限」仅据中心坐标粗分（左 x&lt;90 / 右 x&gt;180 / 上 y&lt;90 / 下 y&gt;180 / 否则中），供目视对图，**不是**区域 ID。
