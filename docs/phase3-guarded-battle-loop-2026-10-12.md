# Phase 3：守卫房间战斗与地图回传

本轮按 Kyries 要求作为一个重型开发主题推进，先合并 #114，再在 `codex/phase3-guarded-battle-loop` 接入战斗与回传，不拆成三个任务。#114 已合并到 main `202a14e`。以下功能属于该后续分支，尚不能当作 main 已交付。

## 已接入

- `startDungeonBattle` 将实际 Ritual Chamber / 怪物部署接入原有战斗引擎。四英雄须有获批属性和三个 I 级装备技能（R-048、R-051）；保留伤口、压力、姿态、意志与状态堆，按 R-055 放置区域。没有重新发起始补给。
- 整场沿用地牢的 RNG 游标、补给与有限宝箱池。战斗期间地图命令冻结；战斗待选决策走战斗处理器。不能用沙盒手动跳过怪物回合。
- 复用同一战斗界面：技能、先攻、怪物选招 / 定位、宝箱、补给、Cornered 均由现有纯引擎处理。换姿态按钮只开放有存活相邻英雄的方向。
- 补 R24 的 Small 挤占：普通怪可将一只 Small 移到有空间的相邻区域；Small 不能反向挤占。英雄可以在含 Small 的满员区继续行动，结束回合时选择挤出，选择前不重复结算 Cornered。Large 保持 R-060 的只移出一名与允许超容量一格裁定。
- 入场对实际参战卡的所有技能作纯函数预检；未完整解析的效果不在正式房间里静默跳过。基础字段获批不等于所有技能效果可用。
- `finishDungeonBattle` 只接受已结束且没有未决选择的战斗；胜利清理房间，Treasure 额外 20 金币，撤退不清理、不发房间奖励，须先离开才能再次进入。全灭 / Q-52 停点保持停止，不推定胜负。
- 结束后按官方 R25：本张房间牌进入本地牢弃牌，不重洗；参战与部署替换牌同余牌洗回 42 张怪物堆；未拾取宝箱依 R-059 回到有限池，已拾取代币保留已消耗状态。回传伤口、压力、状态、意志牌堆、补给、光照与共享金币。重复回传拒绝。
- 后续抽怪使用已经洗好的持久牌序，不在入场时再次重洗；房间 / 怪物分区检查守恒。已清理房间重新进入不触发原奖励。

## 复现与验证

`/?phase=3` 选择「Lair → Ritual Chamber 可战斗」（地图 p1、种子 1885），重置 Radiant，侦察并全员同意，探索到 D，结算零骰，再抽房间、抽怪物、进入并开始战斗。此种子天然抽到已获批怪物，生产牌池没有过滤或换牌。测试英雄装备各自最前面的三个 I 级技能，只是显式测试布置，不代表战役默认装备。

种子 11 的现有布置仍自然抽到待审的 Pliskin / Spitter：保留这次真实部署，入场原子拒绝，不消费 RNG 或奖励。Tomb of Ancestor 等未获批板块同样不替换。

场景测试覆盖真实入场与拒绝、伤口 / 压力 / 装备保持、胜利奖励与一次回传、撤退强制离开、有限牌堆守恒、Q-52 / 损坏输入，以及完整四轮怪物选招、定位、攻击、撤退后继续探索。Playwright 沿用 Phase 3 的三条关键冒烟，在第一条内补真实入场、四轮撤退与返回地图；没有另建全量回归墙。

本地 Node 24.21.0 / pnpm 12.9.1 下 typecheck、lint、Vitest 67 文件 / 646 项、build、Playwright 6 条均通过。已查看真实房间战斗与撤退返回地图的完整截图。lint 与 Playwright 同跑时曾遇到后者重建 `test-results` 导致目录遍历 ENOENT；冒烟结束后独立重跑 lint 已通过，没有把该次失败记为通过。build 保留约 1.35 MB 主包的体积提示。
