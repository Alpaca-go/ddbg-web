# Phase 4：Guild英雄等级升级与技能/饰品槽管理

本主题从 `codex/phase4-hero-defence-runtime`（#191 tip `c903fff`）继续。依据规格书§4.5/§13.2（官方R29/R34）、R-004、R-051、R21：Guild英雄等级+1支付个人4 XP与共享2金，换成下一级已核实英雄卡；技能槽=2+HL、饰品槽=HL；升级新获得免疫不清除已有疾病等效果。

## 改动

- `visitGuild` / `chooseGuild` 增加 `upgrade-hero`：I→II→III逐级，与技能升级共享每次最多两项；属性/`heroStatId`/Life 切到获批下级卡，伤口、压力、怪癖与疾病保留。
- Guild技能升级覆盖**已拥有的七张**（含未装备）：由 `permanentlyRemovedSkillIds` 阶梯推导当前拥有卡；升级未装备技能只写入移除记录与拥有等级，不改装备栏。
- 新命令 `setEquippedSkills`：村庄期间随时从拥有技能中装配恰好 2+HL 张（R11/R32），不占建筑/天数/RNG；待选或未完成回村时拒绝。
- 饰品槽容量继续按 `hero.level`（既有 `trinketPoolProblem`）；本主题不重排村庄持牌，游商买卖与地牢转交边界不变。
- 铁匠仍只服务**已装备**技能；英雄升到II/III后可继续访问铁匠（等级匹配放宽），未装备须先换装。
- 沙盒展示 HL/未装备拥有技能，并提供「装满技能槽」辅助按钮；村庄冒烟按钮文案同步。

## 未装备技能边界（写清）

| 状态 | 行为 |
|---|---|
| 拥有、未装备 | Guild可永久升级；等级经移除阶梯保留 |
| 换装 | 仅能选入当前拥有且未永久移除的卡；槽数必须=2+HL |
| 铁匠 | 不提供未装备技能的临时升级 |
| 正式地牢入口 | 仍只接受I级英雄与3个装备技能；本主题不开放高等级出征 |
