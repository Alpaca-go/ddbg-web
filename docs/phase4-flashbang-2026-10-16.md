## 实现

生成层仅为 p55 增加已核实状态和区间射程注解，校验英雄、卡名、正背等级、页码、份数及含两个 Shuffle 图标的完整同行签名。重生成实际只有 p55 改变；`1t` / `1-2` 的 `numeric=null`、raw/parsed、全局词典与 II/III 保持原状。

完整状态解析器支持目标同行的“Shuffle Push N or Shuffle Pull N”：两侧必须相同正整数且不溢出，未知残余 / 重复目标位移仍拒绝。未给方向的纯技能调用拒绝；公开命令沿用既有掷前方向 `PendingChoice`，选定后再消费一次命中骰。方向待选期间无状态、无行动消耗、无 RNG 推进；无 Crit 栏时不由 Buff / Debuff / 低光照虚构暴击或伤害。

命中才施加 Stun 并排入一次位移；方向选择完成后若落点分岔，再进入既有落点待选并冻结其他命令。续接不重掷、不重复施加状态，不接受上一阶段的旧 choiceId。落空无状态和位移，仍沿用一次行动消耗及未成功使用技能的规则。Stun 防御与 Shuffle 防御独立沿已有层处理；真实 Maggot 的 Stun 免疫不会取消移动。

新增机制测试覆盖两方向全部十骰面、无 Crit / 无伤害、掷前待选冻结及非法选择、方向与落点两段待选、过期拒绝、区域与姿态、公开命令行动 / RNG 仅一次、落空与显式方向一致、真实 Stun 免疫、同行 / 缺防御 / 射程原子拒绝，以及 JSON 往返与种子回放。数据测试覆盖状态黄金值、完整来源漂移、幂等、区间守门及不向 II/III 扩散。
