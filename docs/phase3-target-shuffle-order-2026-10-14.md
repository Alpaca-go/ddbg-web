# Phase 3：暴击压力先于目标 Shuffle

重新对照官方核心规则书第20页页面图像：Self Effects在技能其他效果之前，Target Effects则在其他效果之后（原文“after any other effects”）；上方暴击条将暴击压力作为暴击的附加效果。因此，自身位移先于暴击，目标位移则在暴击及其压力之后。R-031规定每次暴击的压力范围／去重，没有规定把目标位移后的区域当作暴击发生区域。

前两步已分别完成英雄、怪物自身前缀，本步删除目标Shuffle后的压力快照重算与延后追加伤口：暴击当时同区未受击英雄承压，后来进入的新区域不追加或撤销压力。只有带目标Shuffle的结算入口，才在提交目标状态／位移前完成已产生的压力检定；已有意志卡的英雄此时心脏病死亡，就不再承受目标Stun或Shuffle。没有增加新的压力分组裁定，Q-67／R-069仍控制同次暴击事件与追加伤口。

验证更新旧的“目标最终区域承受暴击”断言，改为明确区分自身与目标位移。新增真实Bone Defender技能2在目标Stun／Push之前先完成首次意志或心脏病；死亡取消目标效果、存活才位移、不重复意志／骰面、不可变输入和回放一致。合成目标位移夹具另覆盖单／多目标、同区去重、后来区域不追加压力与生命字段保留。Spiked整面运行时仍须完整验证后开放。
