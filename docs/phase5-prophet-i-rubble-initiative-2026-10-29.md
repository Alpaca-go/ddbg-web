# C-014：Prophet I 区域攻击与伴战先攻（2026-10-29）

基线：`main` @ `8bbcb59`（#369）。本刀完成 C-014 的逻辑区域运行时；C-013 正式几何与生产入场仍待确认。

## 规则依据

- 官方核心规则书 R19 / 规格书 §6.5：多目标共用一次攻击骰，逐名比较 Dodge；允许攻击空区。
- R30–R31 / §14.2–14.3、R-032：先攻按行动次数加入，抽牌时按当前姿态及剩余行动决定行动者。
- R38–R39 / §14.5：先知三次行动；第三次必用 Rubble 攻击有木长椅的区域，每张木长椅独立掷骰；同区两张可攻击两次。已对照本地规则页图像与 `monster_large:p005` 印刷面：slot 3 为 Special、Acc 8 / Damage 9、Crit 0 / Damage 14。Special 的区域语义由规则书提供，不从卡面猜目标图标数量（R-001、R-048）。

## 改动与验收

- 每张木长椅选中所在区全部存活英雄，共骰逐名结算并输出 `monsterSkillTargetsResolved`；重复落区独立攻击，空区仍消费一个攻击骰。
- 各次攻击使用统一生命、压力及阵亡补位；保留生命事件，死亡英雄不进入下一次攻击。多名 Riposte 累加，英雄全灭 / 先知反击致死时立即停止后续攻击。任一后续输入无效，公开命令整次回滚。
- 先知基础先攻增加两张，保留普通伴战各自的一张；三次先知行动后才加入 `actedIds`，下一轮恢复行动额度。死者不加入新堆，普通任务不额外补牌。
- 新增 12 项场景。Rubble 使用 `applyCommand(prepareMonsterAction)`；先攻通过 `startBattle` / `drawInitiative` 验证，调度夹具用统一 `finishTurn` 推进，并显式改变姿态以隔离调度，不冒充完整伴战 AI。英雄生命 / Buff 为测试边界夹具，不是新卡牌数据或几何审批。
