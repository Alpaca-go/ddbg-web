## 问题与修正

开局八颗补给与探索间恢复均已接线，但 `rollDungeonExploration` 的旧校验仅接受 Food / Torch / Tool，误将 Bandage / Potion 判为非法。真实开局或其他奖励获得这两种补给后，虽能选路，却不能掷探索骰。上一块入口冒烟只检查了开局结束和选路按钮，未覆盖这一连续路径。

依据规格书 §5.2 / §5.5（官方 R12、R14，沿用已核对页面）、R-010 / R-045 / R-048。公共池允许全部五种具名面；能否抵消某项危害仍按该危害要求判断。修正探索前校验为复用 `PROVISION_FACES`，不把 Bandage / Potion 当成 Tool / Food / Torch，也不允许池中残留 Wild。

- 新增两模式真实集成场景，固定种子 75：自然任务分布的首个 G 为 Empty，开局真实池包含 Bandage / Potion。依次完成开局、选 G、掷探索骰、按真实骰面承受危险 / 陷阱攻击，进入并清理 Empty；全部八颗保留，然后实际使用 Bandage / Potion 恢复。没有注入骰面、换房间代币、给金币或跳过结算。
- 同时锁定共享 RNG 消耗、输入不变、完整命令回放和 Bandage / Potion 不能作为危害抵消选项。第三项场景验证五种具名面同池，以及未知面、Wild、重复实例、空 ID 和超过 16 颗仍在掷骰前原子拒绝。
- 沙盒入口演示种子改为 75，既有第一条 Phase 3 冒烟扩展到两模式实际进入 G，仍三条阶段 / 六条总冒烟。其余演示种子保持。
