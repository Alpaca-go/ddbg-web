## W-02：战役与牌堆（W3，How to Use 1–5）

1. 战役开始选择地点；英雄不受地点选择限制。当前产品保留核心固定启用的既有约定。
2. 按等级混洗所有启用地点的 Boss 卡，构成 Boss 牌堆。
3. 选择任务时，从启用地点的对应等级任务牌堆抽两张；可同地点两张，或两个地点各一张。
4. 每次出征时，混洗目标地点同等级怪物和通用同等级怪物。不能把其他地点怪物混入。
5. 每次出征时，混洗 Weald 专属奇物和通用奇物。不能直接加入全部核心奇物。
6. 使用目标地点自己的房间牌堆与房间板块。

数据提取结果不构成牌堆资格核准；普通怪物、大型参考卡、Boss、召唤物须分别核对。

## W-03：零容量区域（W3，Note）

Heroes / Monsters 可穿过 capacity 0 的区域，但不能在那里结束其回合。
不能将零容量区域当成不可通行墙；也不能擅自改成“不能结束单次移动”。
区域容量、邻接、墙与高低地依板块几何核对后登记，不按图片坐标自动猜测。

## W-04：Necrotic Fungus（W3）

- 在房间中印有真菌放置符号的区域放置 Necrotic Fungus。
- 场上只要仍有真菌，英雄就不能被治疗；不限同区域。
- 英雄须以造成至少 1 点伤害的技能命中真菌才能摧毁它。
- 真菌是合法技能目标：Dodge 0、Life 1、无抗性、无免疫。
- 不把真菌自动归类为怪物，不擅自授予怪物触发器或先攻。
