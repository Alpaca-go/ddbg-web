## 规则和边界

依据规格书 §11.1 / §11.2（官方 R26）与 §14（官方 R35）、R-064。已查看官方 R26、R35 完整页面：携带上限等于英雄等级；获得时自己装备、给同伴或弃牌，也可弃 / 转交旧件腾位，不能囤积；新装备正面朝上。饰品能力是主动使用，本轮仅获得 / 携带选择，不执行能力或翻面，不启动 Phase 4。

- 来源必须完整 38 张，按明确战役等级组成 14 / 12 / 12 张实体堆；不只保留已复核子集。普通地牢等级按 R35 与饰品池等级一致，配置不符在抽牌前拒绝。沙盒按其明确等级配置，英雄等级只决定携带容量。
- 初次洗牌走地牢共享 RNG；后续抽顶牌不重洗。牌堆、弃牌、携带与待选入牌守恒。缺失 / 缩减 / 重复 / 耗尽停场，不擅自回收弃牌。
- 获得 PendingChoice 可装备到任一有空位的存活英雄、明确弃新卡、弃旧卡腾位，或把旧卡转交有空位的存活同伴。转交保留旧面，新装备正面朝上；转交 / 腾位后仍围绕原入牌继续，不重抽。待选冻结其他命令，完成后只弃一次 Curio。
- R-048：未复核卡仍保留原抽取概率和具体待选卡，禁止装备 / 解释未知效果。玩家可以明确选弃新卡，或者保留当前停点等待数据复核，不自动弃牌。I 级 p009 / p010 / p012 / p014 仍未复核，不更新词典或补数字。
- 单一饰品以外的 Buff / 怪癖 / 金币组合不开放。本轮装备仅记录携带者 / 正反面，不给 Acc、Crit 等添加隐性加成；没有饰品使用命令。战役升级后的跨等级携带模型、完整使用 / 翻面与回村重置留 Phase 4。
