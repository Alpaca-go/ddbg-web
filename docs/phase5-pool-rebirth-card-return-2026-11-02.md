# 重生池原实体牌归还前置

依据R-147/R-148及ROOMS FRONT p14，实现确定性的原实体牌归还纯函数。输入死亡档案、全部当前持牌英雄和共享牌池；成功返回新的持牌者与牌池，失败只返回原因，不改变输入、不消耗RNG。

取回疾病、怪癖、意志及饰品原实体卡，覆盖当前/旧等级牌堆、弃牌、游商陈列和其他持有者。归还饰品使用死亡档案的原朝向；其他英雄只失去指定牌，保留XP、压力、无关持牌及其他数据，跨房间combat副本同步去掉指定牌。前后校验守恒，缺目录、重复档案、当前坏池及待选入牌均拒绝；不复制实体卡、不重洗其余牌。

本批只提供复活流程的归还前置，返回死者仍保留档案原始死亡状态，不写入公开GameState。Q-131已由Kyries确认的R-149解决：交还意志牌时清除原持有者检定标记，下次压力10重新检定，跨房间combat副本同步处理；复活英雄保留原意志牌与标记。尚未接通清场选择、全队压力支付、复活进入驿站及再次入队，Pool of Rebirth仍usable=false；核心盒具名房间几何缺口仍15张。

测试覆盖隐式和显式牌堆、弃牌、陈列、其他英雄持牌、跨等级饰品池、牌序与输入不变及失败不返回部分结果。本刀无UI与可战准入改动，不新增Playwright路径。
