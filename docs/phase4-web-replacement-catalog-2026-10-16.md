# Phase 4：正式网页的赏金猎人替补目录

## 问题与来源

#225已合并为main `e25f9d3`。复查发现引擎测试使用完整规范化目录，而正式网页仍使用仅含四名I级英雄的战斗沙盒目录。因此#213–#223已实现的赏金猎人技能、Scout Ahead和死亡补人流程，在正式网页没有候选可选；原四英雄升级后的属性也不在网页目录中。

依据官方R29、R31、R33及规格书§4.6、§9.4，沿用R-081（四英雄高等级防御）、R-088（赏金猎人三等级属性）、R-089及各技能已有获批映射、R-090–093。没有新增规则或卡面解释，不使用FAQ；本主题不需要重新批准既有数据。

## 改动

- 新增正式任务专用的构建目录，包含原四英雄与赏金猎人共15个已核实属性面、原四英雄84张技能及赏金猎人7张I级技能。构建检查拒绝缺卡；不因属性已批准就纳入赏金猎人II/III级技能。
- 正式任务、后续任务、战斗交接与存读档使用此目录；原单场战斗沙盒仍用四名I级英雄。开局四人和起始技能选择不变，赏金猎人通过驿站成为替补。
- 目录扩充导致旧网页存档快照不匹配。读档可由调用方提供固定的旧目录：先严格验证旧存档及完整命令回放，再仅替换地牢目录和战斗卡目录字段，要求其他状态与新目录回放完全一致。不接受存档自带来源，不信任注入快照，不放宽资源、待选、实体或RNG校验；新存档仍使用原格式版本。
- 更新死亡停点提示，并将既有村庄冒烟的来源改为与正式页面一致的任务目录；同一条冒烟加入自然侦察死亡存档、候选选择、初始技能选择、入队及刷新保存。
