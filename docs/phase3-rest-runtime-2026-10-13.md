# Phase 3：休息恢复事件分组

依据 R-070 / Q-69，同次休息中每名英雄的 Life 分配总量构成一次治疗事件，压力分配总量构成一次压力恢复事件。Infirm、Fast Healer、Resilient 各修正一次，不按每个分配点重复触发。没有分配的恢复类型不触发，因此不能靠分配到其他英雄免费获得自疗或减压。

所有点分配完成后才恢复并消耗柴火；Life、压力下限封顶、死门离开、均分额度、待选冻结、战斗状态同步、输入不变及 RNG 不变均沿原流程。

验证：三种怪癖各分配两点后总量修正；HL2 的 Fast Healer + Infirm + Resilient 并存只各修正一次；零分配不触发；完整目录守恒下走公共命令；原均分、取消、超额恢复、死门与日志回放测试继续通过。页面说明按总量修正，现有三个 Phase 3 冒烟保持。
