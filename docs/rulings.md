# 规则裁定

本文件记录本项目对规则歧义的裁定。规则书没写清、图标缺失，或资料互相冲突时，不在代码或规格书里自行补规则或数值。先查本文件；没有对应裁定时，在 PR 里提出待确认项，等写入裁定后再实现。

## 格式

已裁定条目使用编号 `R-xxx`（从 `R-001` 起），每条包含：

- **编号**
- **日期**
- **问题**
- **裁定**（属于本项目的结论时，标明「本项目裁定」）
- **依据 / 出处**
- **关联待确认**：`Q-xx`（如有）
- **状态**：已裁定 / 已取代

## 流程

Kyries 最终拍板。助手给出选项和推荐，不代替拍板。裁定写进本文件，不只留在对话里。

### Q-25

- **问题**：Damage 和 Wound 是否区分，伤害修正按什么顺序结算，Protection 是否作用于持续伤害？
- **阻塞 Phase 1/2**：是（P2）
- **推荐**：Damage 只指攻击（技能、陷阱攻击、Riposte）；Bleed / Blight / Hunger / Rubble / Trap Room / Curio 是 Wound，不触发「takes Damage」。顺序：基础值 → 类型加成 → 防御方 ±X → 暴击减半类 → Protection。Riposte 按 Protection 前的数值。说明书标为优先。
- **状态**：待 Kyries 确认
