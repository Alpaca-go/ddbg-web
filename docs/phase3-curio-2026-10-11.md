## 最小可跑路径

探索骰 Curio → 玩家选择不用 Torch / 用一个现有 Torch → 完整池首次种子化洗牌 → 揭示顶牌 → 整卡预检 / 结算 → 弃牌 → 续接剩余探索骰 → Empty。

- Torch 决定锁定在揭示之前；不能看牌后补用、重抽或撤销消耗。首次洗牌消耗 23 次 RNG，后续直接抽剩余堆顶；不剔除未核实卡。
- 地牢状态保存完整 catalog、剩余牌堆、当前牌、弃牌、处理英雄、所属骰、Torch 决定与具体停点。牌池始终满足剩余 + 当前 + 弃牌 = 24，重复结算不重复发金币。
- p21 用 Torch 后，三项已核实负面效果被忽略，只发共享金币 10，之后续接骰面。不用 Torch 的 p21 停在完整疾病牌堆 / 施加接口依赖，整卡尚未提交；没有先扣压力或先发金币。
- 未核实卡不结算半张，不把未知行推定为负面以绕过；卡与抽前 Torch 仍保留。原资料恢复后可对当前牌重新校验，无需再次扣 Torch 或洗牌。
- 未被 Torch 抑制的状态需完整英雄抗性 / 免疫资料（R21、R-033、R-048），本刀不把 Curio 错当可无视防御的 Self 技能，也不在探索中滴血、减时。怪癖、饰品与补给奖励的未知图标先留待确认，不接完整被动系统。
- 牌堆抽空停在 Q-61；同卡压力 10 与其他效果的收尾顺序留 Q-62，不猜奖励与死亡次序。非 Empty 房间入口、回村、疾病牌池仍为后续接口。

网页操作：`pnpm dev` → Phase 3 → p1 →「Curio → Empty（标准 p1、种子 1237、先用 Torch）」→ 重置标准模式 → D → 掷骰 → hero-0 第一颗 Curio → 先用 Torch → 结算当前 Curio。

真实种子 1237：布置游标 7，八骰为 Curio、Rubble、空白、Hunger、Rubble、Darkness、Rubble、Rubble；骰后游标 15，首次完整 Curio 洗牌后游标 38，顶牌为 p21。用 Torch 取 10 金币；余下四 Rubble 用四 Tool、Hunger 用 Food、Darkness 选压力 2，最终 G → D 的 Empty 清理。没有强制骰、挑牌或删卡。
