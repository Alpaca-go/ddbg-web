## 与 Weald / 核心格式对应

| 字段               | Weald `room_tile_geometry` | 本刀                            |
| ------------------ | -------------------------- | ------------------------------- |
| `areas[].id`       | 核准后字母                 | 审阅稿临时标签 only             |
| `capacity`         | 核准整数                   | 表中「（提）」                  |
| `elevation`        | `low` / `normal` / `high`  | 仅三角确凿处提案，余 **待确认** |
| `edges`            | `blocked` / `cornerOnly`   | **未登记**                      |
| `deployment`       | 已核准 `markers`           | 语义名 + 待确认区               |
| `geometryVerified` | true（核准后）             | _catalog_ 全 false              |
