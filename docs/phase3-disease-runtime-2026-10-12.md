## 可用范围

- 从官方 R26–29 的具名条目读取疾病与怪癖，不解释卡面未命名图标，不修改原始数据或全局词典。11 张疾病、35 张怪癖完整目录校验身份、印刷页、份数与正负类别；负面抽堆为完整 18 张，不过滤未验证图标的实体。
- 英雄保存 `diseaseId` / `quirkIds`；目录、余牌、弃牌、待替换的负面实体保持守恒。首次需要时按共享 seed / RNG cursor 洗牌；再次抽取不重复洗牌，耗尽不自行回洗。
- 真实 Maggot 命中会感染，落空不感染。首次获得疾病；重复感染替换并弃掉旧病，抽一张负面怪癖。总共已有三个怪癖时，玩家选择替换一个正面；全为负面时永久死亡，保留 `deathReason=madness`，由既有死亡补位与单场收尾处理。
- 怪癖替换使用 `PendingChoice`，选择前冻结其他操作。无目录、免疫栏未核实、非法 / 过期选择、损坏分区或未支持组合整次拒绝，保留骰子游标、行动、补给与状态。
- 接入实际伤害 / 反击、治疗、压力、移动、位移完成、食物消耗、意志骰、光照改变、探索 Rubble / Hunger 与 Curio 前置触发；不从净伤口或压力差推断原因。Damage 与 Wound 按 R-026 区分，Fragile / Syphilis 与本次攻击伤口合并一次死门。
- Hemophilia / Black Plague 与 Anemic / Thin Blooded 按本轮获批 R-063：每次状态施加中各被动最多一次，追加堆仍受已核实抗性 / 免疫与持续时间修正。自身原始效果和追加目标状态分开应用防御，不用空抗性替代缺失资料。
- Ennui / Mercurial 改真实意志阈值；Bulimic 弃另一 Food，不把该弃置再次算作消耗。Lethargy 在移动命令触发，Vertigo 在实际位移完成后触发；多目标与位移待选不重复消耗原技能骰。Bad Gambler 的骰面伤口先于技能效果，死亡时不继续攻击。
- 疾病、怪癖、状态堆、有限牌池与 RNG 随战斗一次回传地图；UI 显示持有的疾病 / 怪癖与替换选择。
