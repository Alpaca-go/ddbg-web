# 重生池全队压力支付与原牌归还事务

依据ROOMS FRONT p14及R-147/R-148/R-149。死亡档案和原牌归还前置已由#543/#544合入，本批组合“存活队员各承受压力+4 → 完整意志/心脏病结算 → 新死者档案与共享卡回收 → 原牌归还”的确定性事务。

先验证档案唯一、身份不与存活队友重复和当前牌池，再执行支付。压力及追加伤口/死门沿用现有被动、光照与饰品修正，不直接改写压力数字。意志检定可能刚抽走死者原牌，因此归还必须在支付收尾后重新计算，并按R-149清除原持有者检定标记。付款造成的新死亡先存档、再执行R-091回收；饰品遗产留给后续公开流程。失败只返回原因，不改变输入、不返回部分扣费结果。

意志结算增加仅供内部事务使用的settleOnly选项：不执行侦察揭示或房间/村庄续接，缺目录等阻塞作为拒绝返回；原有公开命令调用方式及阻塞行为保持原样。同步combat副本后才保存付款死亡档案，避免存档记录过期战斗值。

暂存结果同时保留“支付完成、尚未归还原牌”的四人状态与事件，供后续清场续接使用，不重新执行支付或重掷意志。Kyries已确认R-151：付款导致死亡（包括全队死亡）也仍执行复活；事务保留原牌归还后的结果，不因付款死亡拒绝。实际复活进入驿站仍留待后续入口提交。

限制：本批返回的是prepared事务，包含原队伍和目标档案，不能直接写入公开GameState。它不证明房间已经清场、不复活、不保存驿站、不添加等待英雄代币，也不判断战役失败。后续仍需清场选择/凭据、驿站持牌守恒存储和再次入队。Q-132/Q-133已由R-150/R-151解决；R-150的一次机会（放弃也消耗，离开重返不重开）将在公开清场入口记录，当前纯事务没有房间使用记录。Pool of Rebirth仍usable=false，房间几何缺口仍15张。无UI及可战准入改动，不新增Playwright路径。
