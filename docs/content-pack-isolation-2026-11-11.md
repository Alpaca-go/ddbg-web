# 战役内容包隔离

Kyries 2026-11-11 要求：开局固定核心包，其他扩展可多选；未选扩展的非英雄内容不能进入游戏。后续补充：英雄仍全部可选。因此十八名英雄、属性卡和各等级技能是共享目录，不受扩展勾选限制。此处变更不新增规则数值，也不改变 R-190 的种子和策略约束。

## 包边界

- 核心：Ruins + Darkest Dungeon，原核心 Boss 与最终战流程。
- Weald：Hag I、Cauldron 及其运行时、测试；Brigand Pounder / Shrieker 身份占位。
- Warrens：Swine Prince I / Wilbur、The Flesh I 四部位及其运行时、测试；Brigand Vvulf 身份占位。
- Cove：Siren I / High Tide 及其运行时、测试；Shambler / Drowned Crew 身份占位。

四个扩展 Boss 的实现已移入 `packages/engine/src/expansions/<pack>/boss/`。每包独立登记 Boss 目录和注册入口，核心注册函数不再注册它们。原导出符号保留，避免破坏已有引擎使用方。

## 开局、运行和存档

正式页面默认只启用核心包。开局可勾选 Weald / Warrens / Cove，出征后配置固定，存档面板显示本战役选择。所有英雄仍可直接建队或作为死亡替补，无须勾选其来源扩展。

新战役使用 `createCampaignQuest`。非英雄来源在建池前通过 `sourcesForContentPacks` 过滤：战斗怪物、怪物抽取池、房间、古物、疾病、怪癖、意志卡和饰品。扩展条目使用包命名空间（如 `monster_large:cove:…`）；核心原 `pNNN` ID 及 R-214 两张 ADD_014 Reflection 保留核心归属。未登记的非英雄命名空间拒绝创建，不能自动视为核心内容。

Boss 的设置、描述卡解析、战斗身份解析和威胁被动检查当前战役的包选择。全局注册表只是代码缓存：另一个战役曾启用扩展，不会给当前核心战役授予权限。回村重新出征继续保留同一选择。

`start.contentPacks` 与回放状态共同持久化，读取时从开局配置重建目录，仍完整校验命令和快照；仅修改开局或快照中的包选择会被拒绝。旧档没有此字段时继续使用原目录与原回放行为，不把旧战役静默转换为核心包配置。原 `createCoreDungeonQuest` 保留作历史单任务/沙盒及旧档重放入口，新正式战役由新入口创建。

## 尚未接通的扩展内容

本次只拆分、隔离现有内容，不将 Boss 测试夹具提升为正式卡牌。Weald / Warrens / Cove 的地点任务、房间、完整怪物池和 Boss 正式部署链尚未接入；扩展 Boss 中原本待核实的卡牌引用保持原状态。勾选这些包不会伪造新的任务路线，也不会把其 Boss 塞进遗迹迫近威胁池。UI 明示“地点战役尚未开放”。

任务和村庄事件目前只读取核心目录；Crimson Court、Color of Madness、Master Webber、Butcher's Circus 暂无可启用的正式内容，不显示空的可玩选项。后续接入必须登记包属并使用本战役选择过滤，再按官方规则补齐各地点流程。
