## 实现

两行共用一个实际目标效果框，提取结果只在首行带目标标记。版面整理只对本卡将原框标记沿用到第二行，保留原始 raw/parsed、前面图标清单和图标 ID，不从未知布局推断其他卡作用范围。完整卡名、英雄、等级、页码、正背身份、统计行和效果行漂移拒绝。

新增可选多条条件伤害注解，保留既有单条格式；Zod 和运行时均拒绝重复行及单条 / 多条同时存在。仅 p43 生成两条：Human +1、Mark +2。卡文 Humans 对应既有规范化种族标签 Human，运行时必须读取已验证怪物卡的标签，不依名字或实体伪造标签判定。多个 Human 标签不倍增；多个 Mark 堆抬高 Acc，但 +2 伤害仍只加一次。

命中或暴击时，两个条件各自判断，满足时合计 +3，随后沿已有 Protection / Riposte 路径计算；普通伤害分别可为6/7/8/9，暴击为10/11/12/13。落空不加伤。没有注解的旧视图继续保留未支持效果边界；没有真实种族、畸变 / 冲突注解则整次拒绝，缺值不补。规范化差异只有 p43，II/III、原始 +1/+2 的 `numeric=null`、词典均不变。

新增机制测试覆盖全部十骰面、Human / Unholy / 混合及重复标签、0/1/3堆Mark、Protection / Riposte、真实怪物卡覆盖实体伪造标签、公开命令一次行动 / RNG、Mark for Death→Collect Bounty 的真实死亡与胜利、缺值 / 重复 / 空 / 畸变注解原子拒绝，以及 JSON 往返与种子回放。数据测试覆盖同框第二行继承原标记、黄金两条件、来源漂移、幂等和高等级边界；旧技能视图夹具显式移除新注解，继续验证无注解时不猜数值。
