# Phase 4 首切片：单任务存档与读档

依据开发大纲§3.3、Phase4和核心规格书§14：电子版可随时存档，以初始种子和公开命令日志回放，另带快照及版本号。本次不新增游戏规则，不实现村庄或战役循环。

正式三张基础任务入口、探索地图和房间战斗提供“保存进度”“读取本机存档”。刷新后从任务入口读取继续，正在处理的PendingChoice也恢复；不自动替玩家做选择或重新掷骰。沙盒注入布置不作为正式存档。只有成功命令进入正式回放日志，拒绝的尝试仍显示即时消息。

v1封套包括格式、版本、规则版本、任务/模式/种子/四英雄三技能初始配置、命令日志及完整JSON快照。Zod严格校验初始配置和所有现有公开命令参数；加载时从createCoreDungeonQuest重建并依次applyCommand，对照快照后返回重建状态，不直接安装快照。未知版本、非法命令、无法回放的命令、截断日志或快照与数据不一致均拒绝，UI只在全部验证成功后替换进度。读取不会重复派发到当前游戏，奖励、牌池与RNG由原日志恢复。

保存使用当前浏览器的localStorage单槽，明确点击才覆盖；本次不含自动保存、跨设备同步、导入导出、旧格式迁移或状态快照加速回放。存储被禁用/容量不足时显示错误，已有游戏继续；数据或规则改变导致回放不一致时拒绝读取。后续变更必须按版本处理，不猜测迁移。

引擎测试覆盖真实起点、待选开局补给继续不重掷、含真实战斗的自然任务摘要及战斗PendingChoice、输入不可变，以及不合法存档拒绝。现有Phase3冒烟内加入两次保存/刷新/读取和待选补给续接，不增加冒烟路径数量。

验收：101文件986项全仓测试、typecheck、lint、build及6条既有浏览器冒烟全部通过。浏览器以已有Chromium1234和独立5187端口运行，本机Node24.20.0；默认5173被其他项目占用，GitHub Actions此前因账户付款/支出限制未启动，不把本地通过标为CI全绿。

下一任务：ReturnToHamlet状态和R32返回步骤，随后村庄事件、建筑/准备天数、死亡英雄补充和连续两个普通任务。Phase3人工试玩检查点仍待Kyries确认；存档首切片不代表Phase4整体完成。
