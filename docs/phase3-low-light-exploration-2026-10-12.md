## 范围与依据

已对照官方核心规则书 R14 / R29 完整页面图像。依据规格书 §5.5 / §5.7 / §5.10 与 R-002 / R-003 / R-026 / R-031，开放光照 0–5 的有骰探索及 Trap 房间；不改变抽牌或探索骰概率，不过滤未知数据。

- Stressful Darkness 可选择实际 Torch 抵消、承受基础 2 压力或光照 −1。降光复用 `changeDungeonLight`，只在实际变化时触发全队具名被动；光照 0 不再下降。抵消危险的 Torch 不提高光照，也不触发提高光照被动。
- 降光完成后标记当前骰已结算，再处理压力到 10 与剩余探索骰。缺意志资料时保留已付光照与骰标记，资料恢复后不重复降光、扣压力、消费补给或重掷。英雄死亡冻结移动并等待既有替换接口。
- 低光压力沿用 `triggerDungeonPassive` / R-002，每事件的低光与疾病 / 怪癖追加压力一次汇总。Hunger 无基础压力时不凭空增压；环境 Trap 固定 Acc 8 / Crit 2，仅使用当前英雄 Dodge 与压力修正，不套怪物光照加成。
- Trap 房间混合分配预检使用修正后的实际压力判断 Q-64，避免低光把原本低于 10 的基础压力推到未裁定边界。Q-66 / Q-67 / Q-68 与其他已记 Q 停点继续保留。
- 中文 UI 去掉 Darkness 的过时“待确认”提示与低光照未接线声明。原有第一条 Phase 3 冒烟扩展 seed 31 的 Trap 暴击 → Darkness 降至 4 → Empty → 光照 4 掷下一段八骰，仍保持三条 Phase 3 / 六条总冒烟。
