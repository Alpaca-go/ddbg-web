# Phase 3：探索骰 → 单走廊结算 → Empty

本刀按 Kyries 2026-10-11 指示一次实现这条路径，接在布局 / 侦察 / 压力恢复切片之后。只接探索与 Empty；不重开 Phase 2，Q-52 仍待定停场，不扩展 Boss、完整怪癖饰品或其余英雄技能。

## 来源与数据

规则依据为核心规则书 R14–R15（规格书 §5.4–§5.7）及 R12 补给、R28 压力、R29 死门；裁定 R-010、R-012、R-013、R-026、R-048。已逐页对照本地官方 PDF 图像，另核对印刷 `DD_COREBOX_DICE_D6_Exploration.pdf` p1 骰网、`DD_EN_COREBOX_CARDS_70_120_PLAYER_AIDS_FRONT.pdf` p1 补给与 p5 房间图标。未使用 FAQ。

`exploration_die.json` 录入六面：Curio、Rubble、Hunger、空白、Trap、Stressful Darkness，各一面。Zod 拒绝缺面或重复面。JSON 的面序只是固定软件抽样顺序，没有给骰面编造印刷编号或额外效果。

英雄 HL / Life 来自已批准 `hero_stat.json`；页面沿用 Crusader、Hellion、Highwayman、Vestal 的 I 级卡，姿态依次为 Aggressive、Defensive、Ranged、Support。沙盒的 DL 1、光照 5、起始位置与六个补给明确为测试注入，未实现任务开局补给骰或完整战役。

## 最小引擎路径

`beginDungeonExploration` → 路线 `PendingChoice` → `rollDungeonExploration` → 本英雄选骰 `PendingChoice` → 危险选项 `PendingChoice` → 全部完成后移动。

- 标准每人两骰，Radiant 一骰；侦察只减少紧接着的一次探索，Radiant 减至零，不消费 RNG。
- 按姿态顺序掷出并保存全部结果；按同样顺序逐英雄处理，每名英雄可以选择自己的两骰先后。选骰、选择补给、被拒绝选项均不重掷。
- 空白无事发生；Hunger 用 Food 抵消或承受 `2 × HL` 伤口；Rubble 用 Tool 抵消或承受 `DL` 伤口和一压力；Stressful Darkness 用 Torch 抵消或承受两压力；Trap 可用 Tool 抵消。补给池共享，每次只弃掉选中的一个补给。
- 伤口不走攻击伤害 / Protection 修正（R-026），仅作用于掷骰英雄；复用已有种子化死门函数。首次到死门不掷骰，已在死门再受伤才掷一次。死亡保持原位置，等待替换接口。
- 压力到 10 后保存已完成骰面，再接已有完整意志牌堆；恢复后处理剩余骰面，不重复扣压力、不送侦察减骰、不揭示侦察邻居。缺数据保留停点，可补齐后恢复。
- 全部骰面结算完成前，队伍不移动。进入 Empty 后揭示并标记 `cleared=true`，房间代币移除；`kind` 仅保留已知房间历史，不再代表一个在场代币。
- 灰点停留后交还选路，下一段重新探索且不能侦察。进入非 Empty 房间后停在 `awaitingRoom`，未执行房间奖励、战斗或清理。已访问节点暂不列入探索选项；原路返回须另接 R14 的无骰 / 每走廊一压力规则。
