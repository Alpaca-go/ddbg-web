## 本轮：对空区域使用英雄技能

直接查看本机只读官方 `DD_EN_COREBOX_RULES.pdf` 第 19 页完整页面图像：Targets 允许选择空区域，Accuracy 规定有 Acc 掷 d10、没有 Acc 不掷骰。自身效果沿用 R20 的已实现顺序；R-025 明确空区域算成功使用；R-024 的 Guard 和 R-022 的高地射程照常门控。

- `playHeroSkillEmptyArea` 指定已知、连通、没有存活角色的区域；不以空选列表绕过区域校验。姿态、射程、命名、完整效果与 Guard 在消费 RNG 前核对。
- 复用技能解析及自身生命 / 状态应用；空投影只供卡面校验，不创建战斗实体或借用角色。不判目标命中 / 暴击，不施加目标伤口 / 状态 / 位移 / 光照或暴击压力。自身效果只执行一次，有 Acc 仍掷一次；成功扣行动并锁定重用。
- UI 明确选择空区域，并显示使用者、技能、区域与真实攻击骰。Self 不允许空区域；自身 Push / Pull 因当前位移接口缺区域参照，整次拒绝，不推进 RNG / 行动。不补未核实射程、Nt 或图标。
- 场景覆盖真实 Divine Comfort、Pistol Shot、Stunning Blow，以及低骰、收尾、回放和拒绝原子性；原三条冒烟增加合法 E、断图 F、重复使用与回放。
