## 规则与范围

依据规格书 §13.1（官方 R14–15、R29、QUEST p1）、R-038；已对照官方 R15 / R29 完整页面与 Scout Ahead 已核对的文字 / 房间构成。每清理两个房间获得 1 XP，最多 3；回村时每名英雄领取相同数量，驿站只增加一份同额 XP，不乘英雄人数。

本块只生成待发奖励摘要，不发放英雄 / 驿站 XP，不处理村庄、苦难转怪癖、补给回收、休息或其他任务。未新增卡面或板块批准，不进入 Phase 4。Phase 3 仍未满足至少三张任务卡的验收目标。

## 实现

- 地牢创建时保留已校验的任务 ID / 代币构成，独立复制数组；不由地图页码、当前房间或布局相似性猜测任务。旧状态缺任务身份保持拒绝，不默认补 Scout Ahead。
- `summarizeDungeonQuest` 只能在全员退出后执行一次。核对任务构成、地图房间槽、房间 ID 唯一性与完整性、房间类型守恒、清理 / 揭示记录与所有未完成结算，再生成 Zod 校验的摘要。
- 清理房间 ID 排序去重校验，每两间计 1 XP。Trap / Dark 永不清理，伪清理直接拒绝；重复访问、返回和仅揭示房间不增加 XP。
- 摘要记录 `xpPerHero`、同额 `stagecoachXp` 与 `awarded=false`，保留金币、英雄、牌池、补给、位置和 RNG。重复命令原子拒绝，退出后其他命令仍冻结。
- 中文沙盒新增摘要按钮和清理数 / 待发 XP 展示。既有走廊演示 seed 31 的 G 原为 Trap，却被测试注入为已清理；本轮将 G 与备用 Empty E 的代币互换，保持八枚构成、D 的 Empty 与 RNG，避免错误计分。仍明确是沙盒注入，不宣称真实战役清理了起点房间。

缺任务身份、未知任务、同 ID 错构成、错误 DL、重复 / 缺失 / 非房间节点、未揭示的清理标记、活动房间 / 怪物 / Curio、未完成骰面和房间结算均拒绝。没有奖励失败判定或默认卡牌替换。
