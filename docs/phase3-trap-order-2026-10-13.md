# Phase 3：Trap压力后伤口

依据 R-069 / Q-64，Trap房间同一英雄分配的全部压力形成一次事件，先结算压力、Soft／The Worries追加伤口与死门、存活者意志／心脏病，再对存活英雄支付全部分配伤口。零压力不触发压力怪癖；零伤口不掷死门。死亡取消剩余分配，本房保留代币；不推定任务或战役失败。

压力已支付但意志资料缺失时保留本次尚未支付的伤口。恢复只续接意志和剩余伤口，然后才把英雄标记完成；不能重开分配、导航或用旧选择重复支付。UI展示结算顺序及尚待伤口。

验证：所有DL合法分配、低光混合分配、意志先于伤口、心脏病取消伤口、Soft压力伤口与分配伤口在死门分别两批（第一批死亡取消第二批、第一批存活才第二批）、缺资料修复与完整路径一致、种子回放、原状态不变。更新三个既有Phase3冒烟之一的混合分配路径，不增加回归墙。后续继续Curio、自身Shuffle与板块特殊运行时。
